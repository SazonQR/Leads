Merchant discovery guide

Listen first. Show what matters. Agree on the next step.

Before I show you Sazón, may I ask three quick questions about what is making it harder to grow your business?

Ask permission and record the merchant’s own words. Ask for estimates, not sensitive records. Do not collect passwords, card details, bank details, tax IDs, or customer personal data.

How to save your leads

  1. First save: select Save to Excel. Create Sazon Leads Register.xlsx in your files, or locate an existing register. The guide remembers the selected file name and file reference in this browser.
  2. Later saves: the guide opens and reads the remembered workbook, preserves prior entries, then adds the current interview. Saving the same interview again offers to update its row.
  3. Next merchant: select Start new interview before entering another merchant. Saved register rows are retained.
  4. After reopening the guide: the saved file reference is restored. Grant access again if your browser requests permission.
  5. If the workbook was moved, deleted, or access was revoked: use Locate existing register to reconnect it. The guide cannot search your computer without permission.
  6. If direct file access is unavailable: import the latest workbook first when needed, then save an updated download named Sazon Leads Register.xlsx. Earlier downloads do not update automatically.
  7. Keep backups. Browser storage is local, not encrypted, and not shared between devices. Close the workbook in Excel if a save fails. A selected workbook is rewritten as the three-sheet Sazón register; use a dedicated copy to preserve unrelated sheets or original formulas.

Local-only form: nothing is submitted to Sazón. Browser drafts are optional and not encrypted. Avoid shared devices. Exported files contain contact information; share securely.

Cómo guardar sus prospectos

  1. Primer guardado: seleccione Guardar en Excel. Cree Sazon Leads Register.xlsx o localice un registro existente. La guía recuerda el nombre y la referencia del archivo en este navegador.
  2. Guardados siguientes: se abre y lee el libro recordado, se conservan los registros y se agrega la entrevista actual. Guardar la misma entrevista permite actualizar su fila.

Gabay sa panayam sa merchant

Makinig muna. Ipakita ang mahalaga. Magkasundo sa susunod na hakbang.

Bago namin ipakita ang Sazón, maaari ba kaming magtanong ng tatlong maikling tanong tungkol sa mga humahadlang sa paglago ng inyong negosyo?

Humingi ng pahintulot at itala ang mismong sinabi ng merchant. Humingi ng pagtataya, hindi sensitibong dokumento. Huwag mangolekta ng password, card details, bank account, tax ID, o personal na datos ng customer.

Mga tagubilin sa pag-save ng leads

  1. Unang save: piliin ang I-save sa Excel. Gumawa ng Sazon Leads Register.xlsx o piliin ang dating register. Tatandaan ng gabay ang pangalan at file reference sa browser na ito.
  2. Susunod na save: bubuksan at babasahin ang natatandaang workbook, pananatilihin ang lumang entries, at idaragdag ang panayam. Kung parehong panayam, maaaring i-update ang row nito.
  3. Susunod na merchant: piliin ang Magsimula ng bagong panayam bago maglagay ng ibang merchant. Mananatili ang saved rows.
  4. Pagbukas muli ng gabay: ibabalik ang saved file reference. Payagan muli ang access kung hihingin ng browser.
  5. Kung nailipat, nabura, o nawalan ng permiso ang file: gamitin ang Hanapin ang dating register. Hindi makapaghahanap sa computer ang browser nang walang pahintulot.
  6. Kung walang direct file access: i-import muna ang pinakabagong workbook kung kailangan, saka i-download ang updated Sazon Leads Register.xlsx. Hindi awtomatikong nagbabago ang lumang downloads.
  7. Mag-backup. Lokal, hindi encrypted, at hindi shared sa ibang devices ang data. Isara ang workbook sa Excel kung may save error. Isusulat muli ang tatlong Sazón sheets; gumamit ng dedicated copy para mapanatili ang ibang sheets o original formulas.

Lokal lamang: walang ipinapadala sa Sazón. Opsyonal at hindi encrypted ang browser draft. Iwasan ang shared device. May contact information ang exports; ibahagi nang ligtas.
